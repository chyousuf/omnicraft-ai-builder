# 🚀 OmniCraft AI — Multi-Modal Website Builder for WordPress

**OmniCraft AI Builder** is a WordPress plugin that generates complete, high-converting, animated landing pages in seconds using **Text Prompts**, **Vision AI Screenshots**, or **Reference Website URLs**.

Fully native support for both **Elementor** (drag-and-drop widgets) and **Gutenberg Blocks** with built-in GPU animations and 100% white-label branding controls.

---

## ✨ Key Features

- 🧠 **Multi-Modal Generation**:
  - **Text Prompts**: Describe your business or startup idea.
  - **Reference Website Scraper**: Clone and adapt section rhythm & services from competitor URLs.
  - **Vision AI**: Upload layout screenshots to inspire structure and visual hierarchy.
- 🎨 **Adaptive Section Architecture & Customizer**:
  - Interactive Step 4 Customizer in WordPress Dashboard.
  - **11 Built-in Sections**: Navbar, Hero, Stats, Features, Carousel Slider, Story, Testimonials, Pricing, FAQ Accordion, Final CTA, and Footer.
  - **Dynamic Section Editor & Custom Section Builder**: Edit section tags, titles, and AI prompt directives or add brand new custom sections.
- ⚡ **Standalone GPU Animation Engine**:
  - Enqueues lightweight, GPU-accelerated scroll-reveal animations (`omniFadeInUp`, `omniFloat`, `omniPulse`, `omniGlow`).
  - Animated live number counters on viewport entrance.
- 🛠️ **Multi-Builder Support**:
  - **Elementor**: Native container & widget tree structure.
  - **Gutenberg**: Clean, standard WordPress blocks.
- 🤖 **Universal LLM Provider Support**:
  - OpenAI (GPT-4o, GPT-4o-mini)
  - Google Gemini (Gemini 1.5 Pro, Flash)
  - Anthropic Claude (Claude 3.5 Sonnet)
  - OpenRouter (DeepSeek, Llama 3, Mistral)
  - Custom OpenAI-Compatible Base URL endpoints.
- 🏷️ **100% White-Label Ready**:
  - Customize plugin branding name, logo, menu title, dashboard colors, and credit limits.

## 📦 Installation & Setup

1. Clone or download the repository into your WordPress plugins directory:
   ```bash
   cd wp-content/plugins
   git clone https://github.com/chyousuf/omnicraft-ai-builder.git
   ```
2. Activate **OmniCraft AI — Multi-Modal Website Builder** in **WordPress Admin > Plugins**.
3. Navigate to **AI Site Builder > Settings** to configure your preferred AI provider API key.
4. Go to **AI Site Builder > Create New Page** to start generating landing pages!
